## 📌 Project Overview
An AI-assisted reverse milestone planning system and custom countdown lock screen generator. 

### Key Features
- **AI Reverse-Planning:** Structures deadlines into clear T-minus milestones ($\le 5$ words each).
- **High-Definition Lock Screens:** Optimized for 9:16 vertical smartphone screens with top 32% clock clearance and interactive glassmorphic cards.
- **Showcase Covers:** 3:2 ratio high-resolution device mockup presentation (exceeding 1200px requirement).
- **Live Interactive App:** Real-time ticking countdown to deadline with toggleable checklist and responsive phone frame.
- **Automated Calendar Reminders:** Universal `.ics` calendar file with pre-configured 15-minute advance alerts.
